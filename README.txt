ASV RÉGIE MOBILE — PROTOTYPE 0.1

Contenu : index.html, manifest.webmanifest, sw.js, icon.png, icon-512.png.
Données intégralement fictives. Lecture seule. Aucune connexion à ASV RÉGIE ordinateur.

Pour tester l'interface sur ordinateur : ouvrir index.html dans un navigateur.
Pour tester sur iPhone comme une vraie application hors connexion : publier uniquement ces fichiers de démonstration sur un hébergement HTTPS statique (par exemple GitHub Pages) puis ouvrir l'adresse dans Safari, Partager > Sur l'écran d'accueil > Ajouter. Ouvrir une fois avec Internet, puis activer le mode Avion et relancer l'application.

Attention : un ZIP transmis par AirDrop et ouvert dans Fichiers ne constitue pas une installation PWA. Le service worker n'est activé que via HTTPS (ou localhost). L'application n'est pas encore publiée : le ZIP ne fournit pas d'URL publique.

Ce prototype ne contient PAS d'import de production, ni de véritables PDF, ni de synchronisation. Ces fonctions viendront après validation du test de base.
